# 章节识别与排序规则

本文件说明 `epub_reorder_clean.py` 如何从 EPUB 中提取章节编号并排序。
当排序结果不符合预期、或需要调整排序行为时阅读本文件。

## 1. 标题提取顺序

对 spine 中的每个文档，按以下优先级取标题：

1. 文档中第一个 `h1`-`h6` 标题元素（文档序）
2. `<title>` 元素
3. 第一个非空 `<p>` 的前 60 字
4. XML 解析失败时，用正则兜底匹配 `<title>` 或 `<h1>`-`<h6>`

标题取得后，还会尝试用**文件名**（manifest href 的主干）补充解析编号。

## 2. 章节号识别格式

按以下顺序尝试，命中即止：

| 模式 | 示例 | 说明 |
|---|---|---|
| `第X章/回/节/话/幕/则/篇/集` | 第一章、第十二章、第123章、第三回 | X 可为阿拉伯数字或中文数字（含大写壹贰叁） |
| `Chapter/Chap/CH N` | Chapter 12、ch.5 | 英文标题 |
| 行首数字 + 分隔符 | `123.` `123、` `123:` | 常见于转换质量差的 EPUB |
| 文件名主干数字 | `001.html`、`001_开局.html` | 标题无编号时的兜底 |

卷号识别：`第X卷/部/册`，如"第二卷"。卷号与章号同时存在时排序键为 `(卷, 章)`。

中文数字转换支持：零〇一壹二贰三叁四肆五伍六陆七柒八捌九玖十拾百佰千仟万萬两兩，
可处理"第一百二十三章""第二十七章""二十章"等写法。

## 3. 排序算法

对每个 spine 条目生成排序键 `(卷, 章, 类型, 原索引, 锚点序)`：

- **编号章节**：`(卷, 章, 0, 原索引, 0)` —— 按卷号、章号升序；
  相同编号的多个文件（一章被拆成多页）按原相对顺序排列（稳定排序）。
- **无编号条目**：
  - 标题命中前置关键词（序章/前言/楔子/引子/简介/作品相关/作者的话/写在前面等）→ 置顶；
  - 标题命中后记关键词（番外/外传/尾声/后记/终章/大结局/附录/设定集/感言等）→ 置尾；
  - 其余情况 → 锚定到它在原 spine 中前一个编号章节之后
    （插图页、作者注这类夹在章节间的内容随其相邻章节移动）。

卷号继承：若全书中没有任何卷标记，所有条目卷号视为 0；
若有卷标记，无标记条目继承原顺序中最近一个卷标记（取不到则为 0）。

## 4. 何时跳过重排

- 编号章节少于 2 个，或编号章节不足总条目的一半 → 跳过，
  报告 `no-chapter-numbers` 或 `insufficient-chapter-numbers`。
- 计算出的新顺序与原顺序完全一致 → 不重写 spine，报告"顺序已经正确"。
- 用户传入 `--no-reorder` → 跳过。

跳过重排不影响广告清理，两者相互独立。

## 5. 已知边界

- 多卷书若每卷章节重新从第一章编号，依赖卷标记正确归卷；
  无卷标记且章节重编号时无法区分卷，只能全局按章号排。
- "第X集"按集号视作章级处理，"第X篇"同理。
- 标题中偶然出现的"第X章"字样（如"关于第三章的说明"）会按该编号参与排序。
- 一章被拆成多个文件且标题相同时，保持原相对顺序。
