## 创建 Skill：epub-reorder-clean（EPUB 小说章节重排 + 广告净化）

仓库 E:/RErange 的用途落地为 Skill 制作。本次从零做出 `epub-reorder-clean`：

- **结构**：`epub-reorder-clean/`（SKILL.md、agents/openai.yaml、references/×2、scripts/epub_reorder_clean.py、evals/evals.json），打包产物 `dist/epub-reorder-clean.skill`；测试在 `tests/`（make_test_epubs.py 造测试书、test_epub_reorder_clean.py 31 条断言全过）。
- **核心脚本**：纯 Python 标准库（zipfile + ElementTree），无第三方依赖。功能：按 (卷,章) 稳定排序重排 spine（支持中文数字/第X章/Chapter N/行首数字/文件名编号；序章前置、番外后记置尾、其余无编号条目锚定到前一章）；清理广告链接/短链接/推广文字/广告样式块/裸网址/纯广告页；同步重排 toc.ncx 与 nav.xhtml；清理 OPF 元数据广告字段；按原编码（UTF-8/GBK/UTF-16）回写；输出前完整性校验。
- **关键设计决策**：
  - 广告页移除判定 = 原文本命中广告规则 + 清理后无媒体 + 残留 ≤50 字且清除比例 ≥75%（防误删夹带广告的短章节）；
  - 广告链接文本 >200 字只摘 href 不删元素（防误删正文）；
  - 解析失败文件保持原样；失败过半视为 DRM/损坏中止；
  - 默认不碰原文件，输出 `<书名>_cleaned.epub`；`--in-place` 才备份后原地替换。
- **踩过的坑**：① Windows 上 `os.replace` 目标文件被 zip 句霸占用会 PermissionError——先把全部条目读入内存再关闭源 zip；② ElementTree 移除元素时要保留 tail 文本，否则文字粘连丢失；③ 循环内立即 remove 又与后续批量 remove 冲突导致 ValueError——先标记后统一移除；④ expat 不识别 `&nbsp;` 等具名实体，需预处理为数字引用；⑤ 变量被提前 mutate 导致"是否变化"判断失效（spine 比较要以移除前的原始顺序为基准）。
- **工具链**：make-skill 脚本需要 PyYAML，已建 venv `C:/Users/19105/.workbuddy/binaries/python/envs/default/Scripts/python.exe`（python.exe 在 Scripts/ 下，不在 venv 根目录）。quick_validate --strict 通过，正向测试用子代理按 SKILL.md 独立跑通。
